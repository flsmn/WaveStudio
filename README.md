# Wave Studio

Repository für die Desktop-Anwendung zur interaktiven Simulation optischer Wellenexperimente in zwei Dimensionen.

Dieses Repository liegt unter `WaveStudioApp/WaveStudio/`. Die Simulations-Engine liegt separat unter `../WaveSimulator2D/`. Beide werden über `../WaveStudioApp.code-workspace` gemeinsam geöffnet und unabhängig versioniert.

## Projektstand

Die Projektstruktur und das Git-Repository sind vorbereitet. Anwendungscode, Entwicklungsumgebung und Paketierung folgen dem Development Plan. Es wurde noch kein initialer Commit erstellt und kein Remote für dieses neue Repository eingerichtet.
