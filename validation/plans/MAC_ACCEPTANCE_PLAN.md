# Mac acceptance protocol — frozen before the new runs

Scope: Apple M1 / 8 GiB only. Existing T01–T04 limits remain unchanged. Windows/Linux and public distribution remain deferred. Agent-operated native UI checks are distinguished from automated Qt regression tests; neither is called a human review.

Quality selection must preserve continuous geometry, reference units, source/detector settings and damping definitions. It must account for shortest material wavelength, thin walls/polygons/lenses and propagation distance, and report its actual grid, memory and conservative dispersion estimate before Run. Configurations exceeding the existing 512 MiB numerical-buffer guard or 4096-cell axis limit must be rejected clearly, without changing a valid project or silently reducing quality.

Before measuring the proposed presets, their maximum predicted phase drift over the source-to-detector path (or usable domain diagonal without detectors) is fixed at Preview π, Balanced π/2, High Quality π/4. This is a conservative homogeneous worst-index stencil estimate, not a promise for arbitrary interfaces. Use the axial and diagonal stencil symbols and the actual dt. A measured homogeneous eigenmode must agree with the predicted frequency within 0.1%, and speed error remain below the old T01 2% limit. Include a long-path case (64 reference wavelengths) and a rotated thin material/wall case. Compare the actual selected grids, not labels alone.

Run the double-slit and fixed biconvex-lens probes at each affordable selected preset. Keep T03 minimum error ≤15%, asymmetry ≤3%, wall maximum ≤1e-7; T04 focus error ≤20%, gain ≥1.5. Adjacent affordable lens presets must shift focus by ≤5% of the paraxial back focal distance; investigate failures without widening limits. Record resource-rejected presets as rejected, not physically passed. Existing source/angle/damping/backend tests cover unchanged physics; repeat affected tests after numerical fixes.

Local performance budgets for the existing 512² reference scene: ≥20 displayed snapshots/s with one and two views, pause acknowledgement <100 ms, process RSS ≤1 GiB, warmed idle/pause CPU ≤0.10 CPU-seconds/wall-second and no steps/repeated frames while paused. Economical mode ≤240 steps/s and ≤30 displayed snapshots/s; mode changes must preserve run/grid/measurement identity. These replace the provisional approximately-30-fps aspiration for this Mac; they do not extend to every affordable grid or other hardware. Large grids must retain responsive controls at bounded step boundaries. Record GPU activity when read access exists, and distinguish sampling from a calibrated power measurement.

Native UI acceptance covers Run/Pause/Step/Reset; scene changes without auto-start; all object types; physical and passive handles; Undo/Redo; material order; numeric validation; menu/keyboard paths; known distance 5 and angle 90° at two zoom levels; second-view scale/synchronization; current/reference choice across display changes; save/reopen, invalid files, PNG/CSV and recovery; dark/light themes and 100/125/150% application text at minimum supported window size. Preserve any pre-existing work before replacing or rebuilding a running app.
