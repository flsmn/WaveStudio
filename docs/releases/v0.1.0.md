# Wave Studio 0.1 — macOS (Apple Silicon)

First experimental desktop release for scalar 2D wave experiments. The application includes its Python runtime and WaveSimulator2D engine; no separate Python installation is required.

## Download and install

1. Download **WaveStudio-0.1.0-macos-arm64.zip** from this release.
2. Extract the ZIP and move **WaveStudio.app** to Applications.
3. Launch the app, choose a File-menu example and press Run. Updates currently use manual download/replacement.

**Platform:** Apple Silicon / arm64 only. Bundled libraries declare a minimum macOS target of **26.0**. Tested locally on Apple M1 / 8 GiB / macOS 27.0.1; other eligible systems and an independent clean Mac have not been validated. No Intel, Windows or Linux binary is included.

**Signing:** ad-hoc signed, without Developer ID notarization. Gatekeeper may block first launch. See Apple's instructions for opening a trusted app that has not been notarized: https://support.apple.com/en-us/102445. Do not disable system security globally.

## Included

- Point/line sources, polygonal materials, walls and biconvex lenses; exact properties, dragging and Undo/Redo.
- Run/Pause/Step/Reset, selectable CPU/MPS computation and configurable grid/resource limits.
- Field, material and intensity views, synchronized second view and geometry measurement tools.
- Passive point/line detectors, finite measurement windows, signed field samples and held references.
- Versioned project files, recovery, PNG/CSV export, light/dark themes and editable double-slit/refraction/lens examples.

Application version **0.1.0**, engine **0.1.0.dev5**. This release packages the current implementation; it introduces no numerical-method or tolerance changes.

## Known limitations

- Scalar, linear, static-material, two-dimensional model; no polarization, dispersion, absolute optical-power calibration or full 3D optics.
- Quality presets are advisory. Full quantitative slit/lens qualification and some independent source/reference criteria remain open.
- Native macOS scene-outline accessibility can fail after structural edits; full VoiceOver acceptance is pending.
- Context-dependent GUI pauses remain under investigation. Performance depends on grid, hardware, application and power state.
- Project and complete third-party license/attribution review remain open; no new project license is asserted by this release.

See [current roadmap](https://github.com/flsmn/WaveStudio/blob/v0.1.0/docs/ROADMAP.md) and [numerical scope](https://github.com/flsmn/WaveSimulator2D/blob/6d2c9dc/docs/QUANTITATIVE_PROGRESS.md).

## Verification and assets

`SHA256SUMS.txt` contains checksums for the application ZIP, Python wheels, build information and distribution inventory. The ZIP is the ready-to-run macOS app; wheels are supplementary Python packages and not required for installation. `BUILD_INFO.json` records source commits, dependency versions and the validation scope. The inventory is a static binary/dependency audit, not complete clean-machine or license certification.
