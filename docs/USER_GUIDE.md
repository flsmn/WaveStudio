# Wave Studio quick guide

Start with **File → New experiment**, or open one of the three editable examples. Add objects from **Edit → Add** or the scene panel. Select an object in the list or on its outline, then choose **Edit** for exact coordinates and parameters. Drag an object or its handles to move/reshape it; release commits one edit. Polygons are drawn by clicking vertices and pressing Enter. Material objects later in the list override both index and damping of earlier objects. Walls always block the field. A double slit needs a source and three wall rectangles; no template is required.

**Run** initializes a fresh experiment. **Pause → Run** continues the same run. Physical edits, including Undo/Redo, require Pause and invalidate the old run; only another manual Run starts the changed experiment. **Step** advances an initialized paused run exactly once. **Reset** clears the live field and measurements, keeps held references and stays stopped. Step is disabled until a run has been initialized and paused again. The rate display shows “Measuring rate…” after Run/Resume until advancing frames provide a full interval. Initialization and time spent paused are excluded; paused rates are zero. Frame delivery and numerical step rates can differ.

Switch the main view between Field, Material and Intensity. Field and intensity have separate numeric color ranges; these change appearance only. Intensity is a live exponential preview of relative field squared. View → Second view observes the same simulation and shares its physical viewport. Zoom/pan never changes geometry, grid or measurements. Tools → Measure distance / angle uses two / three clicked points in project coordinates (the second point is the angle vertex).

A passive point detector or detector line can be edited while running. On confirmation, only that detector starts a new measurement revision; the wave field, other detectors and held references continue. Detectors first wait their editable **settling time**, then integrate over a finite **window duration**. The defaults (32 and 16 project time units) are suggestions: allow enough travel time and enough cycles, including beat periods when source frequencies differ. “Complete” means the configured window ended; it is not an automatic assertion of steady state.

Choose a completed profile and **Hold reference**. Up to four references preserve raw values, physical coordinates, original scene and run metadata. The plot uses a common raw scale or one shared maximum for both curves, never separate normalization. Distinct detector paths are identified. File → Export completed profile / reference as CSV writes unnormalized values and metadata; live previews cannot be exported as completed quantitative profiles. PNG captures the main view with a labeled color scale and embedded JSON identifying its scene/run and display settings.

**Save** writes a versioned `.wave.json` file atomically. It contains geometry, stable IDs, display settings, detectors and references, not a resumable wave field. Invalid files are rejected before replacing the current project. One recovery file (up to 8 MiB) is saved every 30 seconds while modified. After an interrupted session the app offers to restore it; a clean close removes it after the save/discard choice. Recovery includes references but no running field.

**Simulation settings** controls domain dimensions, grid spacing, time step ratio, damped border and device. Presets retain the continuous geometry. Preview / Balanced / High Quality use at least 10 / 12 / 20 cells per shortest material wavelength, 2 / 4 / 6 cells per measured thin feature, and predicted homogeneous phase drift no greater than π / π/2 / π/4 over the longest source-to-detector path (usable domain diagonal without detectors). Thin-feature estimates use wall thickness, lens centre thickness and polygon minimum support width; arbitrary concave necks and interfaces still need convergence checks. Presets also avoid wall faces exactly on cell centres, where the half-open inclusion rule can break reflection symmetry; Custom grids show a warning. The dialog shows the actual grid, memory and phase estimate. Manual grid edits choose Custom; geometry/detector changes retain the grid and clear the old preset label. Reapply a preset when the experiment changes. Expert values remain editable and are validated before Run. **Resource limits** in the same dialog are saved per project: numerical-buffer budget (MiB) and maximum cells per axis. Defaults remain 512 MiB / 4096 cells; old files inherit these defaults. The live summary shows requirements, configured limits and a large-grid notice. Runtime, rendering and backend overhead are additional, so increasing the budget is not a guarantee of available memory or speed. Oversized grids are rejected before raster allocation without reducing quality or geometry. For the fixed lens example, Balanced requires 588.7 MiB; explicitly setting 768 MiB admits its unchanged 3780 × 2268 grid. High Quality requires both at least 1323 MiB and an axis budget of at least 5665; it has not been resource-tested on this Mac. Budget-only changes retain the current paused experiment. Run/Resume reuse the prepared geometry. Reset stops the run and releases solver state after the current step; window close shuts down the worker. Device/grid changes require a new manual Run. Economical mode caps numerical steps at 240/s. Commands are checked after at most four CPU steps, one MPS step, and one step for large grids; Performance removes the pacing delay. Display stays capped at 30 snapshots/s. Mode changes preserve numerical quality and measurements. Large affordable grids can run substantially slower than the representative 512² scene. Live field/intensity images above 1024 cells per axis use a marked, bilinearly sampled display preview to bound transfers/rendering. Pause and Step restore full grid detail for inspection; detector integration and the solver always use every cell. The physical image extent stays unchanged. PNG metadata identifies display preview/shape. Reset and shutdown also return unused MPS allocator cache to the system.

The model is scalar, linear, static-material and two-dimensional. Lengths use a fixed project reference length and c0=1; changing source wavelength does not rescale geometry. Source amplitude means integrated forcing strength, not prescribed displacement or optical power. Materials have n∈[1,4]. The outer boundary is a damped zone, not a guaranteed reflection-free PML. There is no polarization, dispersion, absolute power or 3D lens prediction. The coarse reference lens has a broad 20% focus tolerance; arbitrary lens parameters or quality suggestions do not inherit a precision claim.

Use **View → Text size → 100%, 125% or 150%** for larger application and chart text. Toolbars wrap and property dialogs scroll. At the minimum 980 × 660 window size, hide the Measurements dock from View when more space is needed for the canvas. Both views keep square physical units, the same centre and the same scale per screen pixel; different pane widths can expose different horizontal extents.
